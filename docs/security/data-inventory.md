## Rules for this system
- **Data never sent to external providers:** body weight, steps, gym notes, account data, push subscriptions, logs. No health data to any AI provider (`docs/decisions.md`).
- **Data sent only with explicit per-feature consent:** food (meals, macros, water, recipes, plan, shopping list) only through the in-app Assistant (the external Food connector was removed 2026-11-08; its unused `api_tokens` table stays empty). The in-app Assistant sends food context to Anthropic (Claude, through the Claude Code CLI) only when the owner sends a message, and only with the owner's own connected Claude token (a dev build with no token uses the developer machine's own `claude` login). Before enabling: check the training and retention settings of that consumer plan and disable training on chats where the plan allows it (AI.9).
- **Logging excludes:** tokens and secrets, request and response bodies of weight endpoints, food and AI content, push endpoints. Log metadata only (user id, route, status, request id).
- Analytics and tracking: none.
- Deletion removes every row of the user in one transaction, including queue and push entries. Backups age out by retention.
